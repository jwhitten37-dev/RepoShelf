# Support

RepoShelf is pre-release and maintained on a best-effort basis.

- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Use GitHub Discussions for questions when Discussions is enabled.
- Follow [SECURITY.md](./SECURITY.md) for private vulnerability reports.

Before requesting help, run `npm run check` and include the RepoShelf version,
VS Code version, operating environment, and sanitized reproduction steps. Never
post credentials, private source, internal URLs, organization/project identity,
user identity, or ownership-marker contents.
